# 2.9.1 平台基础验收

日期：2026-11-09。基础版本：2.9.1 / build 91，节点 SDK 1。

## 结论

可以开始按目录并行开发常规音频、MIDI、触发、时间码及后台任务节点。新节点可以在自身目录完成描述、实现、专用界面、双语文案与测试，通过构建发现接入平台，不需要添加中央类型分支。

当前约定见 [项目宪法](项目宪法.md)，开发步骤见 [节点指南](编写新节点.md)，逐类适配状态见 [实现映射](节点与连接标准-实现映射.md)。各开发窗口从根目录 `AGENTS.md` 开始。

工程创建时建立时间码和项目设定各一个。节奏属于使用它的节点，公共时间码不携带全局 BPM。全选删除保留环境；复制或跨工程粘贴普通节点时，时间码引用接回目标工程的环境。

## 开发边界

- 既有节点中仍有旧适配实现；它们已分目录，但尚未全部迁入独立内核。按照节点指南逐个适配，不能继续扩大旧类型分支。
- 当前处理接口是 Float32 立体声。处理精度与导出位深分开定义。
- SDK 1 尚未实现通用反馈缓存、Control/Resource/TaskEvent 图内负载、内核私有状态序列化、独立数据图调度和任意 `.cpp`/资源的自动构建发现。这些能力按宪法扩展后才能使用；已知不支持的端口不能静默执行。
- 外部声卡切换、实际 Logic 工程操作和真实 AI 模型生成未在本轮手动验收。任务回归使用可控后端；AU 的构建与签名通过不代表上述宿主操作已实测。

构建输出位于 `build/verify-2.9.1/build/`，验收测试位于 `build/verify-2.9.1/tests/`。本地安装包与含 App/AU 的压缩包位于 `build/`。制品使用本地签名，安装包未签名且未公证。
