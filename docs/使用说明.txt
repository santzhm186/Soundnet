Soundnet 2.25 · 输入 → 节点处理 → 输出

右键画布，可以插入所有类型的节点。同一种节点可以添加多个，每个实例拥有自己的 ID、参数、素材和运行状态。选中节点后在右侧编辑；拖输出圆点到输入圆点建立连接。Shift 点击可增减选择，Shift 拖动空白处可框选；拖动任一选中节点会整体移动。Command+C / Command+V 复制粘贴节点和内部连线，Command+X 剪切，Command+A 全选，Delete 删除；选中连线后按 Delete 可单独删除连线。方向键微调位置，按住 Shift 每次移动 10 点。工具条「复制」「粘贴」「查找」「吸附」提供对应操作；吸附按 20 点网格对齐。

本地 MIDI、DAW MIDI、MIDI Clip 分别是独立节点。硬件音频输入、DAW 音频输入、节奏速度、DAW 时钟、硬件音频输出、DAW 音频输出也各有独立节点。音符线为橙色，音频线为绿色，时钟为紫色，触发线为红色。

逻辑触发
开始与停止节点可以点击按钮发送信号，也能把上游触发转换为开始或停止命令。等待节点把信号延后指定秒数再发出。次数条件每收到 X 个信号后输出一次，然后开始下一轮计数。MIDI Clip 的「循环完成」输出在每轮播放结束时发送触发。多个触发来源可以同时接入同一播放器。

示例
打开 examples/three-loops-then-wait.json，点「开始触发器」，按「发送触发信号」。
第一个 Clip 完整播放三次后自动停止。触发信号同时进入一秒等待，再启动第二个 Clip。两个 Clip 各自控制一个振荡器，混合后输出。示例内嵌 MIDI 和模型映射，打开后即可使用。
此示例使用独立版的硬件输出。在 Logic 中载入后，删除硬件输出，右键添加「DAW 音频输出」并连接混音器。
打开 examples/filter-reverb-noise.json 可试听滤波器与混响：振荡器先经过低通滤波，再进入混响，并与粉红噪声混合。EQ、Delay、滤波器、混响、噪声和音频输出节点可在右侧勾选「旁通」，跳过处理但保留连线。
采样器：右键插入「采样器」，点「载入音频…」。采样器有 16 个复音声部，音符按 Root 移调。Root 为素材原始音高，Start/End 为 0–1 区间，Loop 打开后循环，Attack/Release 为秒，Gain 为 0–1；Reverse 反向播放，Velocity 为力度敏感度。支持 WAV/AIFF，以及 MP3/M4A/AAC/CAF/FLAC（AVFoundation 解码）；单文件最大 64 MB，解码后最多约 4M 个采样点。打开 examples/sampler-pluck.json，用键盘或 MIDI 演奏 C4 可试听。
音频片段：右键插入「音频片段」，点「载入音频…」。把开始触发器接到触发输入，停止触发器可停止；Loop 循环，Start/End 为 0–1 区间，Fade 为淡入淡出秒数，Gain 为增益；Pitch 为半音移调，Reverse 为反向播放。音频片段不需要 Note 输入。打开 examples/audio-clip-reverse.json 可试听。
压缩器：Threshold 为 -60–0 dB，Ratio 为 1–20，Attack/Release 为秒，Makeup 为 0–2 补偿增益，Mix 为干湿比。压缩器有两个 Audio 输入：第一个是主信号，第二个是侧链检测信号；把鼓或另一条音频接到侧链可做闪避。打开 examples/audio-clip-compressor.json 可试听。打开 examples/clip-to-midi.json 可试听 MIDI Clip，并用「文件 → 导出 MIDI…」写出 .mid。
限幅器：Threshold 为开始限幅电平（-60–0 dB），Ceiling 为输出上限（-12–0 dB），Release 为恢复秒数，Gain 为输入增益。放在压缩器与音频输出之间，限制最终峰值。打开 examples/master-limiter.json 可试听。可在右侧勾选「旁通」。
合唱：Rate 为 0.05–8 Hz，Depth 为调制深度 0–1，Mix 为干湿比，Delay 为 1–30 ms 基础延迟。左右声道相位差 LFO，可增加立体声宽度。
颤音：Rate 0.1–20 Hz，Depth 0–1，Stereo 左右相位差，Mix 干湿比。位深破碎：Bits 1–16，Rate 500–48000 Hz，Mix 干湿比。打开 examples/tremolo-crush.json 可试听。
相位器：Rate 0.05–8 Hz，Depth 0–1，Feedback 0–0.9，Mix 干湿比；四级全通滤波产生扫频相位效果。
音阶量化：接在 Note 信号之后。Root 0–11 为调性（0=C），Scale 0 大调 1 自然小调 2 多利亚 3 大调五声 4 半音，Mode 0 最近音 1 向上 2 向下。按住音符时改参数会重新量化；旁通时原样传递。打开 examples/scale-quantizer.json 可试听。

在 Logic 中
将 Soundnet.component 安装到 ~/Library/Audio/Plug-Ins/Components/，在软件乐器轨的 AU Instruments → Soundnet 中加载。DAW MIDI 接收轨道演奏和 MIDI 区域，DAW 时钟提供速度与走带位置，DAW 音频输入接收侧链，DAW 音频输出返回当前轨道。当前版本沿用旧插件标识，同一目录安装一份即可。

独立版
本地 MIDI 接收屏幕琴键、电脑键盘和 CoreMIDI 输入。DAW 可发送到 Soundnet MIDI In。纯 MIDI 工作流可连接 MIDI 输出，从 Soundnet MIDI Out 驱动其他软件乐器。模块速度使用自己的 BPM，DAW 时钟接收外部 MIDI Clock、Start、Stop、Continue 和 Song Position。
音频输入输出使用系统选定的设备。选硬件音频输入节点并开启输入后，App 会请求麦克风权限。
电脑键盘 A W S E D F T G Y H U J K 演奏 C4–C5，Z/X 切换八度，Command+. 停音。

参数
数值参数在右侧提供滑块和输入框：拖动滑块快速试听，输入框可精确输入；整数参数（Wave、Type、音域等）会取整。
在「处理」中添加「三声部编排器」，将键盘、和声走向或 MIDI Clip 的音符接入。高、中、低三个出口分别接各自的乐器。每一路可输入最低与最高 MIDI 音高（0–127，中央 C 为 60），并选择最高音、中间音、最低音或柱式和弦。音域外的音按八度移入，放不下的音名会跳过。
打开 examples/three-voice-arrangement.json 可直接试听。第一个 C 大三和弦分别输出 G5（79）、E4（64）、C3（48）。把中声部织体改成柱式和弦可加厚中声部；只想改变低音时，调整低声部的音域即可。
振荡器 Wave 0/1/2/3 对应正弦、方波、锯齿、三角。Attack、Decay、Release 以秒输入，Sustain、Level 为 0–1，Tune 为半音。
滤波器 Type 0/1/2 对应低通、高通、带通；Cutoff 为 20–20000 Hz，Resonance 为 0.5–20，Drive 为 0–1。混响 Mix 为干湿比，Size 为空间大小，Damping 为高频衰减，Width 为立体声宽度。噪声 Type 0/1 对应白噪声、粉红噪声，Level 为 0–1。
ARP Rhythm 0/1/2/3/4 对应直拍、Bossa Nova、Reggae、Disco、十六分。Arp Repeat 设每音重复次数，Gate 为长度比例。
Clip 的播放、循环输入 0 或 1。接 DAW 时钟时受 DAW 播放停止和定位控制，接节奏速度时以模块 BPM 播放。
和弦与走向可点预制按钮，也可输入 Cmaj7、F#m7 或 Cmaj7 | Am7 | Dm7 | G7，走向最多八个和弦。
模型导入支持 Core ML 单标量音高输入输出，或含 128 项 pitches 的 JSON。导入时计算音高映射，实时演奏直接读取。每实例的映射随工程保存。

保存
工具条「保存」写出版本 3 JSON。每个节点的参数、旁通状态、MIDI/模型/音频素材、位置与连线都在文件中。App 退出时记住当前图，AU 随 DAW 工程保存。旧 JSON 会转为独立实例。
工具条「导出」离线渲染当前图 1–120 秒，可选 44.1/48/96 kHz 与 16/24-bit，写出立体声 WAV。导出会给开始触发器发送一次脉冲，因此 Clip、ARP 等会从头播放；没有开始触发器的图导出为静音；采样器还需要 Note 输入；音频片段需要开始触发器。只有 DAW 音频输出时会自动改走硬件输出路径。无界面导出：Soundnet --export 工作流.json 输出.wav 8。
「文件 → 导出 MIDI…」捕获图中 MIDI 输出节点的音符与控制器事件，写成格式 1 多轨 MIDI（速度轨 + 每个 MIDI 通道一轨；480 PPQ，速度取图中第一个「节奏速度」节点的 BPM（缺省 120），时长 1–120 秒）。无界面导出：Soundnet --export-midi 工作流.json 输出.mid 8。
拖空白处平移，滚轮移动，Command+滚轮缩放，「适配」显示整张图。撤销和重做覆盖节点、参数、连线与素材操作，保留最近 64 步。

录制输出：文件 → 录制输出…，选择 WAV 路径后开始，再次选择“停止录制”保存。录制的是最终输出，16-bit 立体声，最长 60 秒，超时截断。

拖入文件：把 MIDI 文件拖到画布创建 MIDI Clip；把 WAV/AIFF/MP3/M4A/AAC/CAF/FLAC 拖入创建采样器，按住 Option 拖入创建音频片段；Core ML 模型拖入创建音符模型。
