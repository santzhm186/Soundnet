Soundnet 2.9.1 · 输入 → 节点处理 → 输出

左侧「节点库」按输入、处理、逻辑、注释、输出分组列出全部节点：单击条目会把节点插入画布中央，也可以直接把条目拖到画布的任意位置。右键画布同样可以插入节点。同一种节点可以添加多个，每个实例拥有自己的 ID、参数、素材和运行状态。选中节点后在右侧编辑；拖输出圆点到输入圆点建立连接。Shift 点击可增减选择，拖动空白处可框选；拖动任一选中节点会整体移动。Command+C / Command+V 复制粘贴节点和内部连线，Command+X 剪切，Command+A 全选，Delete 删除；选中连线后按 Delete 可单独删除连线。方向键微调位置，按住 Shift 每次移动 10 点。工具条「复制」「粘贴」「查找」「吸附」提供对应操作；吸附按 20 点网格对齐。

窗口可以自由缩放，节点库、画布、检查器和键区会随窗口重排。空白处拖动为框选，Option 拖动或中键拖动平移，滚轮平移；画布左下角的缩放条提供 −、百分比、＋ 和「适配」，Command + 滚轮或触控板捏合以光标为中心缩放。选中若干节点后按 Shift+Command+G 或右键「编组选中节点」，会把它们放进一个分组框：拖动分组标题整体移动框内节点，双击标题重命名，右键解散分组（节点保留）。分组随工程保存。状态栏右侧的「钢琴键盘」开关可隐藏键区；键区为黑白键样式，按下高亮，按住拖动可以滑奏。

本地 MIDI、DAW MIDI、MIDI Clip 分别是独立节点。音频输入和音频输出在独立 App 与 AU 中共用。新建工程自带时间码和项目设定各一个；相关节点自行设置节奏，不设全局 BPM 或独立节奏节点。音符线为橙色，音频线为绿色，时间码为紫色，触发线为红色。

逻辑触发
开始与停止节点可以点击按钮发送信号，也能把上游触发转换为开始或停止命令。等待节点把信号延后指定秒数再发出。次数条件每收到 X 个信号后输出一次，然后开始下一轮计数。MIDI Clip 的「循环完成」输出在每轮播放结束时发送触发。多个触发来源可以同时接入同一播放器。

示例
打开 examples/three-loops-then-wait.json，点「开始触发器」，按「发送触发信号」。
第一个 Clip 完整播放三次后自动停止。触发信号同时进入一秒等待，再启动第二个 Clip。两个 Clip 各自控制一个振荡器，混合后输出。示例内嵌 MIDI 和模型映射，打开后即可使用。
此示例使用通用音频输出，可直接在独立 App 或 Logic 中打开。
打开 examples/filter-reverb-noise.json 可试听滤波器与混响：振荡器先经过低通滤波，再进入混响，并与粉红噪声混合。EQ、Delay、滤波器、混响、噪声和音频输出节点可在右侧勾选「旁通」，跳过处理但保留连线。
采样器：右键插入「采样器」，点「载入音频…」。采样器有 16 个复音声部，音符按 Root 移调。Root 为素材原始音高，Start/End 为 0–1 区间，Loop 打开后循环，Attack/Release 为秒，Gain 为 0–1；Reverse 反向播放，Velocity 为力度敏感度。支持 WAV/AIFF，以及 MP3/M4A/AAC/CAF/FLAC（AVFoundation 解码）；单文件最大 256 MB，解码后最多约 16M 个采样点（48 kHz 立体声约 2 分 45 秒）。打开 examples/sampler-pluck.json，用键盘或 MIDI 演奏 C4 可试听。
音频片段：右键插入「音频片段」，点「载入音频…」。把开始触发器接到触发输入，停止触发器可停止；Loop 循环，Start/End 为 0–1 区间，Fade 为淡入淡出秒数，Gain 为增益；Pitch 为半音移调，Reverse 为反向播放。音频片段不需要 Note 输入。打开 examples/audio-clip-reverse.json 可试听。
压缩器：Threshold 为 -60–0 dB，Ratio 为 1–20，Attack/Release 为秒，Makeup 为 0–2 补偿增益，Mix 为干湿比。压缩器有两个 Audio 输入：第一个是主信号，第二个是侧链检测信号；把鼓或另一条音频接到侧链可做闪避。打开 examples/audio-clip-compressor.json 可试听。打开 examples/clip-to-midi.json 可试听 MIDI Clip，并用「文件 → 导出 MIDI…」写出 .mid。
限幅器：Threshold 为开始限幅电平（-60–0 dB），Ceiling 为输出上限（-12–0 dB），Release 为恢复秒数，Gain 为输入增益。放在压缩器与音频输出之间，限制最终峰值。打开 examples/master-limiter.json 可试听。可在右侧勾选「旁通」。
合唱：Rate 为 0.05–8 Hz，Depth 为调制深度 0–1，Mix 为干湿比，Delay 为 1–30 ms 基础延迟。左右声道相位差 LFO，可增加立体声宽度。
颤音：Rate 0.1–20 Hz，Depth 0–1，Stereo 左右相位差，Mix 干湿比。位深破碎：Bits 1–16，Rate 500–48000 Hz，Mix 干湿比。打开 examples/tremolo-crush.json 可试听。
相位器：Rate 0.05–8 Hz，Depth 0–1，Feedback 0–0.9，Mix 干湿比；四级全通滤波产生扫频相位效果。
音阶量化：接在 Note 信号之后。Root 0–11 为调性（0=C），Scale 0 大调 1 自然小调 2 多利亚 3 大调五声 4 半音，Mode 0 最近音 1 向上 2 向下。按住音符时改参数会重新量化；旁通时原样传递。打开 examples/scale-quantizer.json 可试听。

YuE2 生成 / ACE-Step 生成：右键插入对应节点，两个模型各一个节点。填写风格描述（ACE-Step 为描述）、歌词（可选）、「后端可执行文件」与「模型目录」，在节点面板点「生成」；本机默认可执行文件为 models/audio-cpp/audiocpp_cli，模型为 models/Yue2-3B-GGUF（YuE2）或 models/ACE-Step1.5-GGUF/turbo（ACE-Step）。生成在后台子进程进行，面板显示进度，「停止」可取消（结束子进程，结果不回写）。
产物既内嵌在节点里（工程可独立移动），又在项目设定指定「工程文件夹」后归档到 `<工程文件夹>/AI 生成/<节点名>-<序号>-<时间戳>.wav`；隐藏的「生成记录」保存每次 take 的路径、时长、时间与是否有乐谱，面板下拉可切换某次记录重新嵌入。未设定工程文件夹时只保留内嵌版本。
图内播放走本节点的「触发」端口 → 音频输出（与音频片段一致：开始/停止触发、循环、区间、淡化、增益），节点面板下方另有独立试听：播放/暂停/停止 + 可拖动导航条，不影响图。
YuE2 专有参数：规划深度（关闭/仅旋律/完整）、输出（音频/仅乐谱）、精度（Q4/Q8/BF16）、推理步数、种子、AR/NAR LoRA 路径。「输出」选「仅乐谱」只跑符号规划（stop_after=abc），不生成音频，成功判据是 score.abc。
乐谱闭环：YuE2 生成后乐谱写入「乐谱（ABC）」。检查器点「导入为 MIDI 剪辑」把它转成 MIDI Clip（自动镜像接收音符的下游连线），随后可在钢琴卷帘编辑、量化、编排、导出 MIDI；改完文本在节点面板点「按乐谱重新生成」把乐谱回喂后端重渲染。剪辑节点上的 ABC 是导入时的快照，只用于追溯，不反向同步。转换支持调号、变调记号、附点、连音、和弦、连音组、破节奏与多声部；不展开反复记号。

在 Logic 中
将 Soundnet.component 安装到 ~/Library/Audio/Plug-Ins/Components/，在软件乐器轨的 AU Instruments → Soundnet 中加载。DAW MIDI 接收轨道演奏和 MIDI 区域，时间基准适配宿主走带，节点使用自己的节奏，音频输入接收侧链，音频输出返回当前轨道。当前版本沿用旧插件标识，同一目录安装一份即可。

独立版
本地 MIDI 接收屏幕琴键、电脑键盘和 CoreMIDI 输入。DAW 可发送到 Soundnet MIDI In。纯 MIDI 工作流可连接 MIDI 输出，从 Soundnet MIDI Out 驱动其他软件乐器。模块速度使用自己的 BPM，按公共时间基准安排事件。
项目设定可选择音频设备或跟随系统默认，处理采样率与设备采样率分别显示，必要时由混音器转换。选音频输入节点并开启输入后，App 会请求麦克风权限。
电脑键盘 A W S E D F T G Y H U J K 演奏 C4–C5，Z/X 切换八度，Command+. 停止播放与处理。

参数
数值参数在右侧提供滑块和输入框：拖动滑块快速试听，输入框可精确输入；整数参数（Wave、Type、音域等）会取整。
在「处理」中添加「三声部编排器」，将键盘、和声走向或 MIDI Clip 的音符接入。高、中、低三个出口分别接各自的乐器。每一路可输入最低与最高 MIDI 音高（0–127，中央 C 为 60），并选择最高音、中间音、最低音或柱式和弦。音域外的音按八度移入，放不下的音名会跳过。
打开 examples/three-voice-arrangement.json 可直接试听。第一个 C 大三和弦分别输出 G5（79）、E4（64）、C3（48）。把中声部织体改成柱式和弦可加厚中声部；只想改变低音时，调整低声部的音域即可。
振荡器 Wave 0/1/2/3 对应正弦、方波、锯齿、三角。Attack、Decay、Release 以秒输入，Sustain、Level 为 0–1，Tune 为半音。
滤波器 Type 0/1/2 对应低通、高通、带通；Cutoff 为 20–20000 Hz，Resonance 为 0.5–20，Drive 为 0–1。混响 Mix 为干湿比，Size 为空间大小，Damping 为高频衰减，Width 为立体声宽度。噪声 Type 0/1 对应白噪声、粉红噪声，Level 为 0–1。
ARP Rhythm 0/1/2/3/4 对应直拍、Bossa Nova、Reggae、Disco、十六分。Arp Repeat 设每音重复次数，Gate 为长度比例。
Clip 的播放、循环输入 0 或 1。在公共时间基准下按片段自己的 BPM 播放。
和弦与走向可点预制按钮，也可输入 Cmaj7、F#m7 或 Cmaj7 | Am7 | Dm7 | G7，走向最多八个和弦。
模型导入支持 Core ML 单标量音高输入输出，或含 128 项 pitches 的 JSON。导入时计算音高映射，实时演奏直接读取。每实例的映射随工程保存。

保存
工具条「保存」写出版本 4 JSON：节点以 nodeKey 标识，参数以稳定名称保存（如 filter.cutoff、high.minimum），连线以稳定端口名保存（如 high、sidechain、in2）。每个节点的参数、旁通状态、MIDI/模型/音频素材、位置与连线都在文件中。项目处于早期，不承诺旧工程格式或声音行为兼容。App 退出时记住当前图，AU 随 DAW 工程保存。旧音色 JSON 会转为独立实例。
如果工程里有当前版本不认识的节点，画布用红框标出「缺失节点」，它的连线与参数原样保留，其余部分照常运行与保存；导出时会明确提示工程不完整。
工具条「导出」离线渲染当前图 1–120 秒，可选 44.1/48/96 kHz 与 16/24-bit PCM 或 32-bit 浮点，写出立体声 WAV。导出会给开始触发器发送一次脉冲，因此 Clip、ARP 等会从头播放；没有开始触发器的图导出为静音；采样器还需要 Note 输入；音频片段需要开始触发器。离线导出直接渲染通用音频输出。无界面导出：Soundnet --export 工作流.json 输出.wav 8。
「文件 → 导出 MIDI…」捕获图中 MIDI 输出节点的音符与控制器事件，写成格式 1 多轨 MIDI（速度轨 + 每个 MIDI 通道一轨；480 PPQ，固定速度轨用于编码绝对事件时间，不代表项目全局节奏，时长 1–120 秒）。无界面导出：Soundnet --export-midi 工作流.json 输出.mid 8。
拖空白处平移，滚轮移动，Command+滚轮缩放，「适配」显示整张图。撤销和重做覆盖节点、参数、连线与素材操作，保留最近 64 步。

录制输出：文件 → 录制输出…，选择 WAV 路径后开始，再次选择“停止录制”保存。录制的是最终输出，16-bit 立体声，最长 60 秒，超时截断。

拖入文件：把 MIDI 文件拖到画布创建 MIDI Clip；把 WAV/AIFF/MP3/M4A/AAC/CAF/FLAC 拖入创建采样器，按住 Option 拖入创建音频片段；Core ML 模型拖入创建音符模型。

2.81 界面与运行控制
右上角「中文 / English」可即时切换界面语言并记住偏好，工程中的 nodeKey、端口、参数键、自定义名称保持原样。
工具条分为文件、播放和编辑操作；右侧同类参数按描述符集中为可折叠分组。
左侧节点库支持分类折叠、全部展开/收起，以及中英名称、分类、稳定节点标识即时搜索；清空搜索后恢复原折叠状态。工具条「节点库」可隐藏整个左栏。
「停止」或 Command+. 会持续暂停全图处理并清理待执行的触发、回声、音符及效果状态。点击「播放」或手动开始触发才恢复，调参和外部 MIDI 不会自动恢复。停止不改写工程参数。
WAV、MIDI 与分轨导出支持状态栏「取消处理」，取消不会覆盖已有目标；载入素材也可取消应用结果。系统素材解码或 Core ML 调用无法强制中断，返回后会丢弃取消结果。
钢琴卷帘提供停止按钮；停止、应用或取消编辑会使排队试听失效，试听速度读取当前片段自身 BPM。

2.9.1 节点开发基础
各开发窗口先阅读 AGENTS.md 和 docs/项目宪法.md。新节点放在 nodes/<名称>/，由构建自动发现；参考 gain、midi-split、timecode 的独立内核与 Tests.cpp。旧节点描述符已分目录，仍有算法适配工作，详见 docs/节点与连接标准-实现映射.md。
