Soundnet 1.4  |  音乐工作流
macOS 13 或更新版本，Apple Silicon 与 Intel。独立 App 与 Logic Audio Unit 共用一套工作流。

把 Clip 变成一条能听见的工作流
从「工作流 → 打开工作流 JSON…」选择示例中的 clip-model.json，点「MIDI Clip」并勾选「启用播放」。四拍乐句经音符模型变换音高，交给 OSC 1 播放。时钟节点默认使用模块 BPM，修改速度即可听到变化。想用自己的素材，点 Clip 节点载入 .mid 或 .midi，点模型节点载入模型。关掉「循环片段」可只演奏一次，取消再勾选「启用播放」可在模块时钟下重新开始。

DAW MIDI、本地 MIDI 和 MIDI Clip
在 Logic 中新建软件乐器轨，把 Soundnet AU 放入乐器插槽，选「工作流 → DAW MIDI 演奏」。轨道中的 MIDI 区域和正在演奏的音符由「DAW MIDI」输出。屏幕琴键由「本地 MIDI」输出，两个节点都可以分别连接和弦、力度、ARP、模型或振荡器。
独立 App 的 DAW MIDI 节点接收「Soundnet MIDI In」虚拟端口。请在 DAW 的外部 MIDI 轨道选择该目的地。本地输入接收屏幕琴键、电脑键盘和已连接的 CoreMIDI 输入源。
MIDI Clip 使用标准 MIDI 文件格式 0/1 和基于拍的 PPQ 时间。多轨音符按拍合并，支持音符力度、延音踏板和结尾休止；文件内速度标记由工作流的时钟取代。单个文件上限为 4 MB，最多 32768 个音符或踏板事件。宿主工程和导出的工作流都内嵌 Clip。

选择时钟
在 Logic 中，Clip 的速度入口可直接使用 DAW 速度。要显式选择时间来源，把「节奏速度」接进 Clip 的紫色端口，在速度节点选择「模块 BPM」或「DAW 工程速度」。使用 DAW 时间时，先勾选 Clip 的播放，再启动 Logic 走带；停止、循环和移动播放头会影响 Clip。使用模块 BPM 时，节点从自己的起点播放。相同的速度节点也可分接到 ARP、和声走向、力度。
在独立版中，外部 DAW 可以向「Soundnet MIDI In」发送 24 PPQN MIDI Clock，以及 Start、Stop、Continue 和 Song Position Pointer。只使用本机速度时选「模块 BPM」。

选择输出
青绿色端口传递立体声音频。独立版的「硬件输出」送到 macOS 当前选择的输出设备；插件的「DAW 输出」返回当前乐器轨道，随后可在通道条路由至效果、总线或声卡。
浅橙色端口传递音符。把 Clip、和声、ARP 或模型接到「MIDI 输出」，可用纯 MIDI 工作流驱动其他乐器。独立版在系统中创建「Soundnet MIDI Out」源，在下游乐器或 DAW 选择它作为输入。AU 版通过宿主的 MIDI 输出回调发送音符，接收方式取决于宿主。Logic 中也可用独立版虚拟 MIDI 源驱动其他软件乐器轨。

接入本地模型
选择「音符模型 → 载入音符模型…」。支持 .mlmodel、.mlpackage、.mlmodelc，模型须提供一个 Int64 或 Double 音高输入和一个 Int64 或 Double 标量音高输出，四舍五入后为 0–127。示例 PitchMirror.mlmodel 会把音高 p 映射到 127−p，例如 C4（60）变为 G4（67）。也可以导入形如 {"pitches":[…]} 的 JSON，数组应有 128 项，第 n 项是输入音高 n 对应的输出音高。
Core ML 在导入阶段对所有输入音高求值。实时音频线程使用生成的映射，导出工作流会保存完整映射。适用范围是单音高、无状态的变换。

先弹一个音
打开 Soundnet.app，按下电脑键盘 A，或点底部琴键。默认线路已经接好。MIDI 音符经过 ARP 到达三个振荡器，振荡器和外部音频进入四路混音器，再经过 EQ 和 Delay 送往主输出。ARP 关闭时会传递原始音符。
独立版的 A W S E D F T G Y H U J K 对应 C4 至 C5，Z / X 切换八度。MIDI 键盘自动连接，其他软件可把 MIDI 发到 Soundnet MIDI In。⌘. 停止音符。

在画布上改线
· 浅橙色端口传递音符，青绿色端口传递音频。拖住节点右侧的输出圆点，拖到目标节点左侧的输入圆点后松开。一个输出可以分给多路，同一输入接上新线会替换原线。画布会检查信号类型及循环。
· 点节点，右侧会显示它的参数。也可以用「音符来源」或「音频来源」的下拉菜单来改线或选「未连接」。混音器提供四个独立音频入口。
· 拖节点标题改变位置，拖空白处平移，使用 + / − 缩放。「适配」显示整张图，「整理布局」把节点排回默认位置。
· 右键节点移除模块，同时断开相关线路。可从「节点库」重新添加，或者选中已经在图中的模块。工作流提供 18 个模块槽位，其中有三个振荡器。重新添加的模块需要接线。
· 「撤销」与「重做」用于本次编辑。要从头接线，使用「工作流 → 清空接线」；要恢复能演奏的线路，选择「标准合成线路」。

试一次分层琶音
在「工作流」选「分层琶音」，按住 A+D+G（C–E–G）。OSC 1 直接跟随和弦，OSC 2 和 OSC 3 经过 Bossa Nova 琶音器。点 ARP，把「每音重复」从 2× 改成 1× 或 3×，听旋律换音的速度。休止仍按原节奏型保留。
ARP 有 Straight 8ths、Bossa Nova、Reggae、Disco 和 Pulse 16ths。Gate 设置每音时长，Repeat 可设 1–8。ARP 可接速度节点，使用模块 BPM 或跟随宿主。

编辑一个振荡器
点 OSC 1、2 或 3，选择正弦、方波、锯齿或三角波。每路可设电平、±24 半音移调，以及独立的 Attack、Sustain、Release。A 和 R 以毫秒输入，S 以百分比输入。输入数值后按回车可回到演奏，Tab 可继续编辑，Esc 取消输入。显示 ↳ 的项目跟随共享包络，清空后回车即可恢复跟随。Decay 三路共用。
顶部「音色」提供基础合成、玻璃琴键、圆润贝斯与缓起铺底。选择音色时会载入音色和 ARP 参数，保留当前工作流的线路和布局。

处理外部声音
可从「工作流」选「外部音频效果器」，让外部输入通过 EQ、Delay 直达输出。独立版再点「音频输入」节点，选择「开启输入」。麦克风或声卡由系统设置的默认输入决定，首次使用需要麦克风权限。用麦克风时建议戴耳机，避免扬声器回授。
Logic 中请在插件顶部的 Side Chain 选择音频轨、输入或总线。EQ 的三个频点为 180 Hz、1 kHz、5 kHz，增益范围 ±12 dB。Delay 支持 20–1000 ms、反馈与干湿混合。

保存与加载
「工作流 → 保存工作流 JSON…」会将当前节点、接线、布局、音色和效果参数写入一个 Soundnet JSON 文件。「打开工作流 JSON…」可以在另一台装有 Soundnet 的 Mac 或 Logic 插件中恢复。外部麦克风开关需在本机单独开启。
独立版正常退出时记住当前工作流。AU 版随 Logic 工程保存。打开 1.0 或 1.1 音色时会使用旧版信号路径。

在 Logic 中加载
本机已安装插件时，在软件乐器轨道的乐器插槽选「AU Instruments → Soundnet → Soundnet → Stereo」。升级后重新打开 Logic。若它尚未发现插件，在「Logic Pro → 设置 → 插件管理器」中找到 Soundnet，再重新扫描。
在另一台 Mac 上，将安装包内的 Soundnet.component 放入 ~/Library/Audio/Plug-Ins/Components/ 后重新打开 Logic。两个版本均使用本地签名。


1.3 音乐节点
在「工作流」选择「和声编曲工作流」，再点「和声走向」并勾选「循环演奏走向」。线路为走向 → 力度 → ARP → 振荡器，节奏速度节点同时驱动它们。
和弦节点支持预制和弦及输入名称，例如 Cmaj7、F#m7、Bb7。可以勾选直接演奏，或从 MIDI 根音生成和弦。
走向节点提供预制模板，也可用 | 分隔输入最多八个和弦。每个和弦支持设置小节数，循环输出到下游模块。
力度节点提供正弦起伏、渐强循环、强弱交替，按拍数在最小和最大 MIDI 力度之间改变新音符。
紫色端口传递速度。勾选跟随宿主时，Logic 工程 BPM 优先于节点的手动 BPM。
全套工作流可导出为 JSON。
