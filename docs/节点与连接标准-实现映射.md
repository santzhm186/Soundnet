不能把“已分目录”表述为所有节点均已完成新 SDK 迁移。新增常规节点使用工厂接口，不增加旧运行器白名单。既有节点完成迁移后，移除适配标志、清单条目及无用旧分支，并更新本表。

## 时间与环境

完整新工程默认包含 `soundnet.timecode` 与 `soundnet.project-settings`。局部测试图和导入草稿可不声明完整环境约束。环境节点重复会被校验拒绝，完整工程不能删掉必需环境。

节奏参数归节点。工程图已移除旧时钟、迁移振荡器和未连接哨兵的节点注册。ARP、MIDI Clip、和声走向及力度自动化使用自身 BPM 和公共帧位置，旧时钟端口已移除。旧 AU 参数路由仍保有内部编号，用于旧引擎入口。

通用音频输入和输出由独立 App 或 AU 提供输入缓冲及输出目的地。输入增益按节点实例应用，导出直接使用图的音频输出。独立 App 显示项目处理率和硬件实际率，必要时由混音器转换。设备选择失败不替换当前工程；录音期间不改变音频环境。AU 不控制宿主硬件，实际处理率由宿主决定。

## 校验与版本

参数名按所属节点解析。新节点内部数字 ID 由类型名和本地参数名派生，重复注册直接报错。跨参数约束随节点注册，工程加载和 C++ 图编译共用它。

行为/状态版本必须是有效范围内的正整数。当前模块不支持的版本在编辑模式整体占位，保留原始记录与连线；严格导出拒绝，避免用错误算法解释。当前不承诺旧工程音色一致或建立全量迁移器。

版本目前精确匹配，更新声明不会自动转换已存实例。参数、文本与支持的素材可恢复；SDK 尚无内核私有运行状态的通用序列化接口，`stateVersion` 不意味着任意 `state` 字段或播放游标已接入内核。

## 尚未实现的公共能力

- `Control`、`Resource`、`TaskEvent` 图内端口负载与路由。当前 SDK 对未支持信号拒绝注册，不能仅添加枚举值后宣称可用。
- 完全独立于音频回调的通用数据图求值调度。
- 音频分块存储、流缓冲、计算缓存与跨会话时间域转换。
- 内核私有运行状态的通用保存/恢复回调，以及独立 `.cpp` 和随包资源的模块构建发现规则。
- 所有既有节点完全迁移到公共内核接口。
- 可变延迟补偿与完整的逐节点尾音策略。

这些能力可以按节点需要扩展。先记录接口、线程/所有权、停止失败和保存语义，再实现平台与使用节点。
