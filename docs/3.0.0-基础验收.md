# Soundnet 3.0.0 平台分层验收

日期为 2026-11-10。验证对象为 3.0.0 / build 100 的源码，使用 SDK 2、节点包 ABI 2 和磁盘工程 v6。

## 实现范围

- 46 个注册模块（含隐藏开发样例）均有独立目录测试，通过公共内核、后台任务或元数据合同接入；注册节点不再使用 `legacyAdapter`。
- App/AU 从 `.soundnode` 目录加载节点。普通更新只编译节点包；公共 SDK、平台程序和其他节点保持不变。描述符、参数、面板、文案、预设与资源归节点维护。
- 生产宿主没有实例图时保持静音，不回退内嵌历史乐器；历史 AU 参数字段不构成另一套可执行节点目录。
- 包候选整批校验后原子发布；校验失败保留旧目录。旧代码、面板和资源快照保有原内容，失效任务不能提交。加载后的接口错误、重复键、资源损坏和版本不匹配有明确诊断。
- 平台统一保存工程结构、当前素材与全部生成历史。磁盘 JSON 与同名 `.assets` 一起移动；未知节点仍可保留其自描述资源。AU 状态保持自包含。
- 独立 SDK 只含公共头文件、平台链接库、构建器和文档。外部节点构建不需要 `src/`、中央编辑器或其他节点源码。

## 验证边界

- AU 自动验证覆盖 MIDI 事件偏移、输入隔离、双声道侧链、工程状态恢复、非法修改保留、刷新命令、宿主暂停/恢复/定位和编辑器。它不是 Logic 工程内的人工操作验收，也没有安装或替换现有插件。
- 本机运行验证为 Apple Silicon。Intel 架构的构建结果由最终通用二进制检查确认，不等于 Intel 机器实跑。
- 本轮没有重新执行真实 ACE-Step/YuE2 大模型生成，也没有进行外置音频/MIDI设备切换或录音实测；相关节点的接口、任务归属、取消、结果与历史资源由自动测试验证。
- 本地产物使用临时签名，未经 Apple 公证。
- 普通节点更新不要求重启；进程的二进制镜像、包资源快照和注册目录修订各有 512 个保留预算，达到预算须重启。节点行为/状态版本精确匹配，当前不提供任意私有状态自动迁移。
